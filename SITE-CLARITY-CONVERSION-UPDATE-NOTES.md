# Brodley Locksmiths Site Clarity & Conversion Update

This update is a customer-facing wording and user-experience cleanup. It does not add a large number of new pages. The purpose is to make the site feel more natural, easier to use, and less like an SEO build.

## Main improvements

- Removed the heavy repetition of “planned” and “planning” from visible website copy.
- Reworded homepage sections so the site speaks more naturally to customers.
- Kept the intended business focus on lock changes, uPVC door repairs, key safes, security upgrades, security surveys and gate security without overusing the word “planned”.
- Reworked shortcut/link sections so they read as helpful navigation rather than SEO blocks.
- Reduced service-page link overload by keeping fewer, more relevant related-service links.
- Reworded Areas, Services, Services & Areas, Contact, Quote and Get Secure copy for clearer customer use.
- Kept the SEO structure, service pages, town pages, sitemap, schema and internal linking in place.
- Kept vehicle locksmith work excluded.
